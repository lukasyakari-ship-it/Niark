NIARK
=====

Mobile-first character chat prototype.

v0.2 groundwork:
- Character creator with personality, intro, scenario, greeting, examples and source link.
- Local profile + profile picture.
- Character search.
- CHAI source links can be saved and opened from a character chat.
- GitHub Actions cloud debug APK build.

Important:
- The first APK still needs network access to load the WebLLM JavaScript runtime and model files.
- Google/Gmail authentication is not faked in this prototype. A real backend/OAuth layer is required for production accounts.
